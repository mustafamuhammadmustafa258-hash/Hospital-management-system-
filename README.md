# Hospital-management-system

1. BLUF (Project Purpose)

Hospital Management System is a C++ console-based application used to manage patient records. It allows users to add, display, search, and discharge patients easily.

2. Dependencies

- Operating System: Windows / Linux
- Language: C++
- Compiler: GCC (g++)
- Standard: C++11 or later

3. Installation

1. Download or clone the GitHub repository.
2. Open the project folder in a C++ compiler.
3. Compile and run the program.

Compile Command:

g++ main.cpp -o hospital

Run Command:

./hospital

4. Minimal Working Example

Input:

1
101
Ali
25
Fever

Output:

Patient Added Successfully!

The program successfully stores and displays patient records during execution.
